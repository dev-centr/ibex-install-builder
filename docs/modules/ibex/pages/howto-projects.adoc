= How-to: installer projects
:description: Scaffold installer.kdl and build with a plugin.
:navtitle: Installer projects

== Create

[source,bash]
----
ibex new-project . --plugin=portable-zip
----

This writes `installer.kdl` and a short `INSTALLER.adoc`.

== Edit

Set `name`, `version`, `id`, `publisher`, `plugin`, optional `exe`, `add-to-path`, `files`, and plugin-owned `extras { }` (see xref:howto-plugin-tools.adoc[plugin tools]).

== Build

[source,bash]
----
ibex build .
# or override:
ibex build . --plugin=nsis
----

Artifacts land under `dist/`. Emit scripts/specs without compiling:

[source,bash]
----
ibex emit .
ibex plugins open-gui inno .
----

== CI without a local package build

To emit workflows only (GitHub Actions, GitLab CI, Azure Pipelines, Jenkins, CircleCI, Bitbucket):

[source,bash]
----
ibex new-project . --intent=ci-pipeline --runner=github-actions
# or later:
ibex emit-ci .
----

See xref:howto-emit-ci.adoc[How-to: emit CI pipelines].

== From DevCentr

* New menu / Content Create → Packaging → **Installer Project**
* Toolbar → **New Installer** (Package or **CI pipeline only**)
* CLI: `dev-center --mode=new-installer --path=…` or `--mode=emit-ci`
